# Bucs Basketball Stats

A free, offline-friendly basketball stat tracker for youth teams. Runs in any phone browser; add it to your home screen to use it like an app. All data stays on the device it's used on.

- Track points (1/2/3), assists, turnovers, steals, rebounds, blocks and fouls
- Fast substitutions, undo, minutes played, box score and season totals
- Share the box score with your coach
- Works with no signal once it has loaded once

## Beta (online sharing)

`beta/` adds optional online features using Firebase (free plan): a live view-only link for parents, a team page with past games and season totals, and a second "helper" phone for tracking stats. Only first names and last initials are uploaded. Security rules are in `firestore.rules`.
